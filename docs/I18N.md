# i18n — deep-dive (Phase 2b)

> Locales, translation, pluralization, number/date formatting, RTL.
> Competes with Flutter's `flutter_localizations` + intl and Qt's QTranslator
> + QLocale — pure Zig, no ICU dependency (the ICU binding is the documented
> upgrade path for full CLDR tables and native digits).

## Architecture

```
ui/i18n.zig         I18n — locale registry, tr/trArgs/trPlural, formatNumber/formatDate
                    Locale — ARB parsing + per-locale format data (en/fr/ja/ar)
                    pluralCategory — CLDR plural rules (en/fr/ja/ar)
                    Direction + process-global setCurrent/current/direction
ui/layout.zig       RTL mirror: TextAlign.start/end + resolveAlign,
                    Alignment.mirrored, EdgeInsetsDirectional, flexLayout
                    main-axis reversal
widgets/text.zig    textX — start/end text alignment resolved against the direction
widgets/layout.zig  alignLayout/stackLayout mirror + the paddingDir widget
widgets/i18n.zig    l10nText / L10nText(Args) / l10nPlural / l10nPluralSig
i18n_main.zig       demo app (4 locales, scripted switches, CI smoke)
locales/*.arb       en/fr/ja/ar message catalogs (@embedFile)
```

Two layers: `ui/i18n.zig` is UI-agnostic (registry, messages, formatting,
direction); `widgets/i18n.zig` binds it to the tree. The direction is
process-global (`direction()`, like the input router / timeline) — the layout
layer reads it, so every horizontal flex, alignment and start/end inset
mirrors automatically.

## Locales (ARB)

- `addArb(tag, json, dir)` — ARB is JSON; `@`-prefixed keys (`@@locale`,
  `@key` metadata) are skipped. The direction is explicit (ARB has no
  direction field; `applyFormatData` also sets it for `ar`).
- `tr(key)` — current locale → fallback locale → the key itself. Borrowed
  slice, no allocation.
- Re-registering a tag REPLACES the locale (hot reload of translations);
  the current locale pointer is fixed up.
- Loading: embed at compile time (`@embedFile`, see the demo) or read the
  file with the platform file API and pass the contents to `addArb`
  (Zig 0.17 moved the fs API to `std.Io` — the file read is app-side).

## Interpolation + pluralization

- `{name}` placeholders are filled from a comptime args struct:
  `trArgs(i18n, alloc, key, .{ .name = "Léa" })`. Supported types: ints,
  floats, bools, strings. Unknown placeholders are left as-is.
- ARB plural blocks `{count, plural, =0 {...} one {...} other {...}}` with
  CLDR category rules (en: one is exactly 1; fr: one covers 0 and 1; ja:
  other only; ar: zero/one/two/few/many/other). `#` and `{count}` expand to
  the count; other `{name}` placeholders interpolate alongside.
- `parsePlural` / `selectPlural` are public — custom plural UIs (steppers,
  "N selected") can reuse them.

## Number/date formatting

- `formatNumber(value, opts)` — 3-digit grouping, per-locale separators
  (en `1,234,567.891`, fr `1 234 567,891`), fixed decimals, percent.
- `formatDate(date, kind)` — pattern tokens: `y` full year, `yy` 2-digit,
  `M`/`MM` numeric, `MMM`/`MMMM` month names (per locale), `d`/`dd`.
  short/medium/long per locale: en `10/7/26` / `Oct 7, 2026` /
  `October 7, 2026`; fr `07/10/2026` / `7 oct. 2026` / `7 octobre 2026`;
  ja `2026/10/07` / `2026年10月7日`; ar `7/10/2026`.
- Pure Zig tables for en/fr/ja/ar (built in via `applyFormatData`).

## Direction (RTL)

- `setLocale` flips the locale signal (`locale_sig`); when the direction
  flips, `on_direction_changed` fires — the app marks the root
  layout-dirty and the whole tree re-mirrors.
- The layout layer mirrors automatically: horizontal flex reverses the main
  axis, `Alignment` / `TextAlign.start|end` and `EdgeInsetsDirectional`
  (start/end insets) resolve against the direction. `paddingDir` is the
  directional padding widget.
- Golden test: an RTL row paints the logical order right → left (exact
  pixels, gap preserved).

## Runtime switching + the localized widgets

```zig
const i18n = try I18n.init(allocator, "en");
try i18n.addArb("en", en_arb, .ltr);
try i18n.addArb("ar", ar_arb, .rtl);
i18n_mod.setCurrent(i18n); // process-global (single-window P0, like the router)

const t  = try l10nText(allocator, i18n, "title", .{});                 // re-resolves on switch
const g  = try L10nText(Args).text(allocator, i18n, "greeting", .{ .name = name }, .{});
const p  = try l10nPlural(allocator, i18n, "items", count, .{});        // fixed count
const ps = try l10nPluralSig(allocator, i18n, "items", count_sig, .{}); // count signal
```

- The widgets subscribe to the locale signal through an `Effect`:
  `setLocale` re-resolves the text AND re-measures (the width may change →
  `markLayoutDirty`) + repaints (`markDirty`).
- `l10nPluralSig` also subscribes to the count signal — both the count and
  the locale re-resolve the text.
- The args struct is stored by value; its string slices are borrowed (build
  args from literals or app-lifetime data).
- `L10nTextOptions.text_align` defaults to `.start` — directional by
  default (RTL-aware).

## Demo + tests

- Demo: `zig build i18n` — 4 locales (en/fr/ja/ar) embedded via
  `@embedFile` (`src/locales/*.arb`), scripted switches (frames
  30/150/300/450 → fr/ar/ja/en), a plural with +/- buttons, a
  number/date/direction row, RTL-mirrored boxes, `paddingDir`. CI headless
  smoke (600 frames).
- Unit tests: ARB parsing, tr fallback chain, interpolation (types, unknown
  placeholders), CLDR categories (en/fr/ja/ar + region tags), plural
  parse/select/`#` expansion, branch placeholders alongside `#`,
  formatNumber (grouping/separators/decimals/percent), formatDate (patterns
  per locale and kind), direction + `setLocale` signal/direction callback.
- Widget tests: resolve + locale switch (dirty + layout-dirty flags),
  args interpolation, plural per locale, pluralSig re-resolve on count
  change and locale switch.
- Goldens: localized text renders (presence) across a locale switch; RTL
  row paints the logical order right → left (exact pixels).
